Blog API project consisting of: 
- A backend API repo (backend-api)
- two separate front-end repos: 
    - one for regular users for viewing the site (reader)
    - one for uploading and editing blogs (admin)

backend-api: 
    - Express
    - Prisma 
    - JWT
    
reader
    - processing of JSON data from backend
    - views: 
        - log in & sign up
        - home
        - blog:
            - add comments

author
    - processing of JSON data from backend
    - views: 
    - log in & sign up
    - admin home
    - create blog
    - edit existing blog
